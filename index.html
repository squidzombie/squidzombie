02 How I build

Different apps, the same few rules.

i.

Your data stays with you

Nothing here has an account, a tracker or a server. Sable makes zero network calls, FlowTime never connects to the internet, and Squid is built to live on a single Mac.

ii.

Calm beats clever

No streaks, scores or charts screaming at you. Plain words, reminders that know when to stop, and nothing on screen that calls you late.

iii.

Promise only what the code does

“Not read by default,” not “unreadable.” Every claim about privacy or permanence has to be true of the code, and then the code gets built to keep it true.
